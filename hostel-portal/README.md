# Smart Hostel Maintenance Portal

React + Vite + Tailwind CSS single-page app. No backend required — all data is stored in `localStorage` with realistic seed/demo data.

## Run

```bash
npm install
npm run dev
```

Open the printed local URL (usually http://localhost:5173).
